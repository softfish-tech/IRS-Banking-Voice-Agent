# Intent classification baseline results (Part A)

Generated by `scripts/train_intent_baseline.py`; do not edit by hand.

- Dataset: BANKING77 (CC-BY-4.0), train 10003 / test 3080, 77 intents.
- Dev: stratified 12% holdout of train, seed 42 (1201 examples); used for model and `C` selection.
- Test is scored once, after refitting on the full train split.
- Command: `scripts\train_intent_baseline.py --encoder --save-model models\intent_tfidf_linear_svc_calibrated.joblib`
- Environment: Python 3.12.14, scikit-learn 1.9.1, numpy 2.5.4.

## Notes

- Macro-F1 is the metric required by the proposal: it weights all 77 intents equally, which matters because the train split is uneven (35-187 examples per class).
- `majority` is the trivial lower bound; the TF-IDF models are the working baselines. `encoder_logreg`, when present, is a frozen sentence encoder with a logistic-regression probe (`--encoder`).
- The route-level section above is a mapped view of the same predictions. It is still a BANKING77 score: `fraud_suspicion`, `fee_complaint`, and `product_recommendation` are only partly or not at all represented in the dataset, so they are covered by the rule layer and the scenario tests instead.
- Reproducing the encoder rung needs `sentence-transformers`; the default run reproduces the TF-IDF ladder alone in about 20 seconds.
