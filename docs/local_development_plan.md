# Local development plan

The previous E local-development plan is retired because it described the
pre-integration state in which real A and C were unavailable. The active,
detailed E roadmap is now
[`e_integration_implementation_plan_local.md`](e_integration_implementation_plan_local.md).

Use that plan for the next delivery priorities:

1. guarded, measurable expansion of LLM understanding;
2. semantic context memory for multi-turn conversations;
3. complex single-turn and multi-turn evaluation data; and
4. public-API frontend integration, including reviewable speech-to-text input
   and structured answer presentation.

The authoritative contracts remain `docs/module_api_contract.md`,
`docs/scenario_table.md`, `docs/module_ownership.md`,
`docs/engineering_conventions.md`, and the executable definitions in
`src/banking_agent/schemas/`.
