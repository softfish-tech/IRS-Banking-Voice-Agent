# IRS-Banking-Voice-Agent

Modular prototype for a safe banking service agent. The initial phase establishes shared contracts and a text-only mock integration path before voice, production models, or real banking integrations.

The canonical shared state is implemented in `src/banking_agent/schemas/state.py`. See `AGENTS.md` for local development rules, `docs/module_ownership.md` for module responsibilities, and `docs/` for integration contracts.
